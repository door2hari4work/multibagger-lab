# Agent 5 - Skeptic
Argue the framework fails live. Read other agents' reports once available and attack them.
- Regime dependence: which conditions lose money (narrow-breadth markets, small-cap crashes, rate shocks, momentum crashes
  after sharp reversals, policy/SEBI actions, circuit-locked stocks).
- Capacity/liquidity, tax (STCG/LTCG on turnover), cost drift, data-vendor differences, behavioural failure
  (will the user hold through the drawdown?).
- Multi-bagger base rates: how many 5x names exist vs how many the rule would have to catch; false-positive cost.
- List explicit "this framework loses money when..." conditions and a kill-switch / stop-using-it criterion.
Output `reports/5_skeptic.md`.
